# Dexup-Website

Page de présentation de [Dexup](https://dexup.netlify.app), l'app pour suivre sa collection de cartes Pokémon TCG.

Site statique, sans build : `index.html`, `styles.css`, `script.js` et `assets/`. Même direction artistique que l'app (monochrome, police en points Doto, icônes en matrice de points reprises de [DexupApp](https://github.com/DexupTeam/DexupApp)).

## En local

```bash
python3 -m http.server 5180
```

puis http://localhost:5180.

## Déploiement

Netlify, dossier publié : la racine (`netlify.toml`). Les captures d'écran de `assets/screens/` viennent de l'app en taille téléphone (390 × 844).
